monsun · norns simulator

A 16-tap rhythm delay and a 64-tooth comb resonator for norns, grid 128 and arc 4, after the Intellijel / Cylonix Rainmaker. The real monsun.lua script and the real norns parameter libraries run in a Lua 5.3 virtual machine in your browser; the sound comes from a browser version of the engine.

Grid pages

  • TAPS: the 16 columns are the 16 taps. Rows 1–6 are faders for the parameter chosen on row 8 (level, pan, cutoff, Q, pitch, filter type); press across columns to draw. Row 7 mutes taps and flashes as each tap fires. ALT + row 7 picks the tap the arc edits.
  • RHYTHM: row 1 groove (16), row 2 groove amount, row 3 grid and beat length, row 4 stack and time-LFO wave, row 5 feedback tap (press the lit key again for ALL, ALT for comb size), row 6 feedback pitch, row 7 slip. Row 8: tap tempo, clock sync, L/R pans, delay on, feedback 0, pitch 0.
  • COMB: row 1 tooth pattern, row 2 density, row 3 slope · feedback type · routing · size source · glide · pluck. Rows 4–7 are a keyboard in fourths (C is marked) that tunes and plucks the comb; ALT + key tunes without plucking. Playing a key always brings the comb into the mix (at least 50%). Density keeps the latest teeth; tooth 64 is the comb size and sets the note, so low densities (1–16) sound most like a string, and all 64 evenly spaced teeth cancel the note into a bright, high shimmer. Row 8: octave −/+, pluck, exciter, comb on, feedback 0.
  • PRESETS: rows 1–6 are 96 slots, 1–12 factory. Press to recall with morph. Hold SET A or SET B (row 8, keys 6 and 7) and press a slot to choose the two presets that arc ring 1 crossfades. Hold SAVE (key 10) or ALT and press a slot to save. Row 7 chooses what RANDOM changes; key 5 cycles the morph time, key 8 clears the buffers.
  • Shift-click keeps a key held, which is how you hold ALT, SET A, SET B or SAVE with a mouse.

Arc and norns

  • Arc follows the grid page. TAPS: tap select, its value, global pitch, mix. RHYTHM: beat time, groove amount, feedback, tone. COMB: pitch, feedback, density, delay ‹› comb. PRESETS: A ↔ B, LFO depth, LFO rate, grain size. Hold ALT for fine steps. Drag up or down, or scroll.
  • norns: E1 screen page (TAPS, RHYTHM, COMB, MIX), E2 select, E3 change. K2 freeze, K3 ping (on COMB: pluck).

MIDI

MIDI notes play the comb: the note tunes it, velocity sets the pluck. MIDI clock sets the tempo when clock source is set to midi in the parameters. Without a MIDI keyboard, your computer keys play it too: A to K are the white keys, W E T Y U the black ones, Z and X change octave.

What is simulated

          
Exact: the Lua script, norns parameters, clock, grid and arc LED output, the screen font. Close: the sound. This browser engine is the reference the SuperCollider engine will be built to match: same tap times, pitch shifting, filters, feedback, freeze and reverse, comb teeth and feedback types. Presets you save here last until the page is closed.
